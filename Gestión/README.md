## Metodología

El proyecto sigue **Scrum con sprints semanales**, alineado con la indicación del docente:

| Ceremonia | Día | Foco |
|---|---|---|
| Sprint Planning | Lunes | Definir tareas del sprint |
| Daily / Check | Miércoles | Verificar progreso, desbloquear |
| Sprint Demo | Sábado | Demo de funcionalidad terminada |
| Sprint Retro | Domingo | Retrospectiva y ajuste para sprint siguiente |

Ver detalle en [`../Documentación/01-Metodologia.md`](../Documentación/01-Metodologia.md).
